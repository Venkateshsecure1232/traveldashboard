# Wanderly — Travel & Booking Dashboard

A responsive React + Vite travel management dashboard with trips, destinations, customers, bookings, payments, calendar, charts, filters, and CRUD interactions.

## Requirements
- Node.js 18+ (recommended)
- npm

## Run locally
```bash
npm install
npm run dev
```
Open the local URL printed by Vite (usually http://localhost:5173).

## Production build
```bash
npm run build
npm run preview
```
